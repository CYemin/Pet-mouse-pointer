# 黑猫抱箭头

圆脸黑猫、金黄眼睛、奶白色功能指示符，共17种Windows鼠标状态。当前为静态CUR版本。
默认48px，另附32/64/96/128px尺寸。

## 使用

1. 完整解压ZIP。
2. 双击「应用鼠标主题.cmd」应用48px，或「应用大号鼠标.cmd」应用96px。
3. 双击「恢复原鼠标.cmd」恢复应用前的方案。安装器保留原方案备份。
4. 预览：打开preview.html；保留旁边的frames目录。native-review.png展示48px实际尺寸及3倍放大。

也可运行 install-theme.ps1 -Size 64 选择其他尺寸。安装只影响当前用户。

## 验证与限制

- 本机Windows原生加载、绘制、文件结构及热点检查通过，覆盖102个文件。
- 安装及恢复脚本已进行语法与WhatIf检查；制作过程中未应用系统指针。
- 点击点设在箭尖、食指尖、铅笔尖或对应功能符号的中心；预览可显示热点。
- 17种状态均为静态；未实现随真实鼠标点击改变动作的程序。
- 未测试桌面点击手感、多显示器和不同DPI；32px会损失猫脸细节，建议从48px或64px开始。
- sources目录包含本轮生成素材、提示词、设计说明与热点配置；verification.json为格式和本机验证结果。
