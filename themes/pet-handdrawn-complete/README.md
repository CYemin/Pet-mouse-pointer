# 小狗的17种心情 · 手绘鼠标指针

基于用户确认的侧面手绘方向制作。每个状态独立设计表情或动作。
默认48px；32、64、96、128目录提供固定尺寸备选。

## 预览

`preview.html` 与 `frames/` 保持同目录，可直接用浏览器打开。网页以PNG帧模拟，系统使用CUR/ANI。
`theme-overview.png` 是整套总览；在预览页可切换深浅背景、尺寸及热点标记。
青色十字只在预览中出现，不在实际指针文件里。

## 安装（当前用户，无需管理员）

把主题包解压后，在这个目录打开PowerShell：

```powershell
.\install-theme.ps1 -Size 48 -WhatIf
.\install-theme.ps1 -Size 48
```

首条命令只预览动作。正式安装会将文件复制到当前用户 LocalAppData\PetCursorThemes 下的独立目录，
先备份受影响的原指针注册表值，再应用全部17个状态。主题包之后可移动；安装目录请保留。
脚本会输出备份位置。它应用当前指针设置；若希望在鼠标属性下拉列表中保存名字，请手动“另存为”。

恢复：

```powershell
.
estore-theme.ps1
# 也可指定安装时输出的路径：
.
estore-theme.ps1 -BackupPath "实际备份目录\restore-backup.json"
```

恢复会保留已安装文件和备份，便于再次切换。若系统策略不允许运行脚本，可使用下面的手动方法。

## 手动安装与恢复

1. Win+R 输入 `main.cpl`，打开“指针”选项卡。
2. 先把当前方案“另存为”备份。
3. 依照上表逐项选择对应CUR或ANI文件；选好后将新方案另存为并应用。
4. 手动安装后请保留原文件路径。恢复时选择之前保存的方案并应用。

## 已验证与限制

- 覆盖17个角色；102个文件通过本机Windows原生加载、尺寸与热点检查。
- 检查了192个嵌入帧的CUR结构和热点，并使用原生DrawIconEx绘帧。
- 动态状态为正常、链接、帮助、后台工作和等待；其余状态保持静态，便于操作。
- 安装脚本做了语法及WhatIf检查；本轮未实际应用或恢复系统方案。
- 尚需用户在桌面实际体验、不同DPI和多显示器下验证。部分应用使用自己的指针。
- 细腻手绘在32px会损失细节，建议先试48px或64px。动画帧仍有轻微纹理变化。
- ANI是循环动画，不能仅凭文件响应每次按下鼠标的动作。
- 详见 `verification.json`。

## 源素材与制作

使用内置imagegen生成，随后分帧、标定热点、缩放并编译。原始宠物照片不在此包内。
本地项目 `assets/theme-expressive/` 保存本轮生成素材、各状态完整提示词、热点校准和编译配置。
本地 `pet-cursor-skill/` 是通用Skill源码项目。代码许可证与照片/生成素材的使用权分别处理。


完整解压后，可双击「应用鼠标主题.cmd」应用48px、「应用大号鼠标.cmd」应用96px、「恢复原鼠标.cmd」恢复原设置。
