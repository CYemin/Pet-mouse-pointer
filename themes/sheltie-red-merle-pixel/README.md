# 红陨石喜乐蒂 · 像素指针

完整 17 状态动画指针，提供 32/48/64/96/128px，默认 48px。

完整解压后双击 `安装鼠标主题.cmd`，直接应用默认48px，不询问尺寸；安装成功后自动打开“鼠标属性 → 指针”；恢复用 `恢复原鼠标.cmd`。
无需 Python 或管理员权限，应用前自动备份原设置。

打开 `preview.html` 可检查每个状态、深浅背景、实际大小及点击热点。`focus-preview.gif` 展示正常、帮助、等待、链接。

本套包含 179 张源动作导出帧；毛发循环、问号弹缩、睡着/ZZZ/醒来，以及其余功能动作均有动画。
普通点选以鼻尖定位，文字、准星、缩放、移动、手写采用对应功能接触点。

Windows 原生检查通过：102 个文件、1074 个嵌入帧。
所有状态已在48/96px逐帧复查，包括首尾过渡。记录见 `motion-review/visual-review.json`。
两个双击入口已用预演模式检查，系统鼠标设置未改变。桌面点击手感、不同DPI和多显示器切换仍需实际试用。
轻微像素轮廓及毛发纹理变化可能存在。动作峰值与循环平均变化率见清单，休息停留有意放慢。
