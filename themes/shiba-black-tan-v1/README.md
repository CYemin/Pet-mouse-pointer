# 柴犬 · 黑柴

沿用喜乐蒂粗像素风格，朝左上方的单眼侧面造型；不含参考图胸背、项圈或牵引绳。点选类以可见鼻缘为热点，文本、手写、定位及缩放用各自操作标记。

Windows完整17种动画状态，32/48/64/96/128px，默认48px。完整解压后双击「安装鼠标主题.cmd」；「恢复原鼠标.cmd」恢复首次备份。五个「当前指针改为Npx.cmd」只改当前宠物。包内preview.html可查看全部动作。

原生加载/绘制、热点、像素与安装器预演报告随包提供；未在制作机应用主题。桌面点击手感、DPI与多屏需实际试用。生成动画可有轻微局部像素纹理变化。

绘图使用内置imagegen；generation-prompts保存逐状态提示词。用户原始照片不随包提供。
