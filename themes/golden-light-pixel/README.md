# 浅金毛

版本：1.0.0。完整17种动画状态，32/48/64/96/128px五种尺寸，默认48px。

## 安装与恢复

完整解压后，在主题文件夹中双击：

- `安装鼠标主题.cmd`：直接应用默认48px，不询问尺寸；安装成功后自动打开“鼠标属性 → 指针”。
- `恢复原鼠标.cmd`：恢复应用前备份的指针设置。

无需Python或管理员权限。应用前自动备份当前设置，运行窗口会保留成功或错误信息；恢复不会删除备份。
系统需要的ANI文件会复制到用户目录。连续应用本项目主题时，若原备份有效且当前完整方案仍属于本项目，会保留最初的恢复基线。

打开`preview.html`可试用尺寸、深浅背景、热点及点击区域，请保留`frames/`。网页显示PNG动画，系统使用ANI。
若系统策略阻止脚本，可Win+R输入`main.cpl`，在“指针”页手动分配；应用前先另存原方案。

## 动画与验证

- 17种状态，共174张导出动画帧；动作过渡峰值20FPS，睡眠和表情停留有意放慢。
- 鼻尖用于普通点选；文本、准星、缩放、移动与手写采用各自清楚的功能接触点。
- Windows原生检查：102个文件、1044个嵌入帧通过加载、绘制、尺寸和热点检查。
- 已复查全部174帧在48/96px下的相邻过渡与首尾衔接，详见`motion-review/visual-review.json`。
- `motion-review/`提供逐帧图、原速和慢放GIF；自动检测只提供线索，不能单独代替视觉复查。
- 轻微像素轮廓变化仍可能存在；真实桌面点击手感、不同DPI与多显示器切换需要实际试用。
