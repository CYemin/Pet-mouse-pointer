# 安装与使用

## 安装、调整与恢复

| 系统 | 安装 | 尺寸 | 恢复 |
|---|---|---|---|
| Windows | 完整解压，双击所选颜色目录中的`安装鼠标主题.cmd` | 默认48px；包内提供32／48／64／96／128px入口，只调整当前款式 | 双击`恢复原鼠标.cmd`，恢复安装前的设置 |
| macOS | 安装[Mousecape](https://github.com/alexzielenski/Mousecape/releases)，导入所选.cape，选中后Apply | 32pt／48pt，含1×／2×图像 | Mousecape菜单`Capes → Restore Defaults` |
| Linux／麒麟／UOS | 按颜色目录中的说明复制到用户图标目录，在桌面外观设置中选择 | 32／48／64／96／128px，取决于桌面设置 | 在外观设置中选回原主题 |

Windows安装和调整均无需Python，主题源目录请完整保留。Windows 7使用兼容入口和15种系统支持的光标；较新Windows使用17种。macOS映射13组源状态，兼容普通与Retina显示；其余角色保留系统行为。
